[#introduction]
== Introduction

The Getting Started app is an Android app that uses a database manager singleton.
It's no exemplar of a real application, but it shows the shape of the API.

You can access the `GettingStarted` project on GitHub here: +

[#getting-started-app]
== What the App Demonstrates

The Getting Started app shows examples of the essential Couchbase{nbsp}Lite operations on Android:

* Initialize the library
* Create a database
* Create a collection
* Create a document
* Retrieve a document
* Update a document
* Query documents
* Create and run a replicator

[IMPORTANT]
====
The replicator in this sample targets a Sync Gateway at a hard-coded address, with hard-coded credentials.
Without a Sync Gateway running at that address, the app logs replication errors after the CRUD operations complete.
The rest of the sample still works.
Remove the `replicate()` call if you do not want the errors.

To sync against Couchbase Capella instead, see xref:android:tutorial-cloud-sync.adoc[Add Cloud Sync].
====

[#add-the-app-to-your-own-project]
== Add the App to Your Own Project

. Create a new *Empty Activity* project in Android Studio
. Create a new Application class, similar to the `GettingStartedApplication` class
. Copy the `DBManager` class to your project
. Create a ViewModel and an Activity, like the ones in the sample
. Build and run
+
You should be able to create a document and persist it to the database.

[IMPORTANT]
Android Gradle Plugin 8.0 and later require a build JDK of 17 or later.
Couchbase{nbsp}Lite itself imposes no JDK requirement.
Set your app's Java language level to 11 or higher in `compileOptions` and `jvmTarget`.
Check *Settings > Build, Execution, Deployment > Build Tools > Gradle > Gradle JDK*
if Gradle fails to start.


Using this app with Sync Gateway and Couchbase Server requires working installations of both.
See xref:sync-gateway:start-here:get-started-install.adoc[Install Sync Gateway].
