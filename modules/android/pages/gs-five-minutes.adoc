You build a single-screen Android app that opens a local Couchbase{nbsp}Lite database, saves a document, queries it with {sqlpp} for Mobile, and displays the result.

Everything runs on the device.
You do not need a Couchbase Capella account, a cluster, or a Sync Gateway.


== Prerequisites

* Android Studio, current stable release
* An emulator or device running API level 22 or higher
* Kotlin and Jetpack Compose, which Android Studio selects by default for a new Empty Activity project

For the full supported platform matrix, see xref:android:gs-prereqs.adoc[Prerequisites].

== Step 1: Create a Project

In Android Studio, create a new project using the *Empty Activity* template. Set the minimum SDK to *API 22* or higher.

== Step 2: Add Couchbase Lite

Add Couchbase{nbsp}Lite to the `dependencies{}` block of your app-level `build.gradle.kts`:

[source,kotlin,subs="attributes+"]
----
dependencies {
    implementation "com.couchbase.lite:couchbase-lite-android-ktx:{major}.{minor}.{maintenance-android}{empty}"
}
----

New Android Studio projects already include `mavenCentral()` in `settings.gradle.kts`, so you do not need to change your repositories.

Sync the project when Android Studio prompts you.

[NOTE]
====
This is the Community Edition.
To use the Enterprise Edition, swap the dependency for `couchbase-lite-android-ee-ktx` and add the Couchbase Maven repository.
See xref:android:gs-install.adoc[Install] for the full instructions.
====

== Step 3: Add the Code

Replace the contents of `MainActivity.kt` with the following:

[#ex-five-minutes]
====
[source,kotlin]
----
package com.couchbase.android.fiveminutes

import android.os.Bundle
import androidx.activity.ComponentActivity
import androidx.activity.compose.setContent
import androidx.compose.foundation.layout.Column
import androidx.compose.foundation.layout.fillMaxSize
import androidx.compose.foundation.layout.padding
import androidx.compose.material3.Text
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.couchbase.lite.CouchbaseLite
import com.couchbase.lite.Database
import com.couchbase.lite.MutableDocument

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        CouchbaseLite.init(this) // <.>

        val database = Database("getting-started") // <.>

        val collection = database.createCollection("hotels", "inventory") // <.>

        collection.save( // <.>
            MutableDocument()
                .setString("type", "hotel")
                .setString("name", "Hotel Couchbase")
                .setString("city", "Manchester")
        )

        val query = database.createQuery( // <.>
            "SELECT name, city FROM inventory.hotels WHERE type = 'hotel'"
        )

        val hotels = query.execute().allResults().map {
            "${it.getString("name")}, ${it.getString("city")}"
        }

        setContent { // <.>
            Column(Modifier.fillMaxSize().padding(24.dp)) {
                hotels.forEach { hotel -> Text(hotel) }
            }
        }
    }
}
----
<.> Initialize the library once, before any other Couchbase{nbsp}Lite call
<.> Open a local database, creating it on first run
<.> Create a collection named `hotels` in a scope named `inventory`
<.> Save a document to the collection
<.> Query the collection with {sqlpp} for Mobile
<.> Render the results on screen
====

[NOTE]
====
This example runs its database calls on the main thread to keep the code short.
Move database work to a background thread in a real app.
See xref:android:database.adoc[Databases].
====

== Step 4: Run It

Run the app on your emulator or device.
The screen shows the hotel you saved, read back through a {sqlpp} query against the local database.

== What You Just Built

* A Couchbase{nbsp}Lite database stored on the device, with no network involved
* A document saved to a named scope and collection
* A {sqlpp} query that returns that document to your UI
