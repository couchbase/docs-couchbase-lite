== Build a Getting Started App

This section explains how to validate your configured build environment by building a starter app that uses common Couchbase{nbsp}Lite features.

// TIP: The GettingStarted app can be downloaded from GitHub link:https://github.com/ibsoln/cblGettingStarted.git[GettingStarted].

The GettingStarted app demonstrates how to use Couchbase{nbsp}Lite.
Console and Web App versions are available.

.Development-type Scenarios
[tabs]
====

Desktop App::
+
--

TIP: Make sure you added the Couchbase{nbsp}Lite dependency to your `build.gradle` file

Create, build, and run a new project using the following `GettingStarted.java` code:


[source,java]
----
include::example$GetStartedDesktop/src/main/java/com/couchbase/gettingstarted/Main.java[tags=getting-started,indent=0]
----

<.> Initialize the library
<.> Create a database
<.> Create a collection
<.> Create a new document
<.> Retrieve document and log its ID
<.> Retrieve the document as mutable and change the `language` to `Kotlin` and save it
<.> Query the database output count and id to log
<.> Optionally, start a replication

When you run the app, the console displays the document ID and property.
It also displays a query result showing the number of rows in the database.

This shows that the app persisted the document to the database.

See <<about-the-getting-started-app>> for more on the app itself.

== About the Getting Started App

// Legacy anchor kept so any existing links to #bmkAboutGettingStarted still resolve.
anchor:bmkAboutGettingStarted[]
The GettingStarted app does the following:

* Create a database
+
The app creates its database in the `/getting-started.cblite2` directory relative to its root location when run.
See xref:java:database.adoc#lbl-find-db-loc[Finding a Database File].
+
TIP: Explicitly state your required database location when creating your database.
For more information, see xref:java:database.adoc#lbl-find-db-loc[Finding a Database File].

* Add content to the DB
* Run a query counting the DB rows
* Start a one-shot, bidirectional replication using Sync{nbsp}Gateway and Couchbase{nbsp}Server
* Produce a report on the DB contents
+
