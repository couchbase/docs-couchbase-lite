== Overview

Couchbase Lite Enterprise Edition for React Native is a Native Module implementation that uses TypeScript.
It has feature parity with Couchbase Lite implementations on other platforms, with the exceptions noted below.

You must have https://www.couchbase.com/pricing/[Couchbase Lite Enterprise license] to use this plugin.
This plugin is not compatible with Couchbase Lite Community Edition.

For full API documentation, guides, and reference material, see the https://cbl-reactnative.dev/[Couchbase Lite for React Native documentation].

== Platform Support

This plugin supports iOS and Android only.
Web, Windows, and macOS are not supported.

== Limitations

The following Couchbase Lite features are not yet supported in this plugin:

* Vector Search -- currently in beta on native platforms.
* Peer-to-Peer Sync -- the plugin does not include a platform-specific discovery mechanism.

=== Why Use Expo?

Couchbase recommends using Expo for React Native development.
Expo simplifies setup and configuration.
See https://cbl-reactnative.dev/StartHere/prerequisites[Prerequisites] for Expo-specific setup instructions.
