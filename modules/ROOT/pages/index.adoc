== Couchbase Lite

Couchbase Lite is an embedded NoSQL database designed for mobile and edge devices. 
It enables applications to store, sync, and query data locally—even without network connectivity.
You can use Couchbase Lite as a standalone embedded database within your mobile apps. 
You can also use Couchbase Lite with Sync Gateway and Couchbase Server to provide a complete cloud to edge synchronized solution.

== Why use Couchbase Lite?

* *Offline-first support*: Applications work without needing a constant internet connection

* *Local data storage*: Store and query data directly on the device

* *Secure sync*: Bi-directional data sync with the cloud via Sync Gateway

* *Cross-platform SDKs*: Build consistent experiences across Android, iOS, and more

== Key Capabilities


* Full CRUD operations, Full-Text Search, and SQL++ query support

* Vector search capabilities for AI-powered applications

* Peer-to-peer sync and cloud sync via Sync Gateway

* Secure local storage with built-in encryption

* Conflict resolution and revision tracking

* Lightweight footprint for constrained mobile/IoT environments
