== Couchbase Lite
++++
<div class="card-row">
++++

[.column]
====== {empty}
[.content]
Couchbase Lite is an embedded NoSQL database designed for mobile and edge devices. It enables applications to store, sync, and query data locally—even without network connectivity.

You can use Couchbase Lite as a standalone embedded database within your mobile apps. You can combine Couchbase Lite with Sync Gateway and Couchbase Server to provide a complete cloud to edge synchronized solution.

== Why use Couchbase Lite?

++++
<div class="card-row">
++++

[.column]
===== Offline-first support
Applications work without needing a constant internet connection

[.column]
===== Local data storage
Store and query data directly on the device

[.column]
===== Secure sync
Bi-directional data sync with the cloud via Sync Gateway

[.column]

Build consistent experiences across Android, iOS, and more

== Key Capabilities

++++
<div class="card-row">
++++

[.column]
===== Core Database Features
* Full CRUD operations, Full-Text Search, and SQL++ query support
* Vector search capabilities for AI-powered applications
* Secure local storage with built-in encryption

[.column]
===== Synchronization & Conflict Resolution
* Peer-to-peer sync and cloud sync via Sync Gateway
* Conflict resolution and revision tracking
* Lightweight footprint for constrained mobile/IoT environments

===== Architecture Context
You can use Couchbase Lite as a standalone embedded database within your mobile apps, or with Sync Gateway and Couchbase Server to provide a complete cloud to edge synchronized solution.

*Couchbase Lite* ↔ *Sync Gateway* ↔ *Couchbase Server*

For edge deployments: *Couchbase Lite* ↔ *Edge Server* ↔ *Sync Gateway*
