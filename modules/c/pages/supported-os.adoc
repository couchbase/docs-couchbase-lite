[#officially-supported-versions]
== Officially Supported Versions

Couchbase Lite for C is available on the platforms shown in the tables below.

[IMPORTANT]
.Deprecation Notice
--
Support for the following will be deprecated in this release and will be removed in a future release:

* macOS 13 (Ventura)
* Windows 10

Please plan to migrate your apps to use an appropriate alternative version.
--

[#android]
=== Android

[IMPORTANT]
--
These requirements are for the *C/C++ SDK* on Android (e.g., when using Qt or other C++ frameworks).

If you're developing with the *Java/Kotlin SDK* on Android, see xref:android:supported-os.adoc[Couchbase Lite for Android - Supported OS Versions].
