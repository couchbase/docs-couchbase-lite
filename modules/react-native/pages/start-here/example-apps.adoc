= Example Apps

Several example apps are available for developers to review.  These apps are designed to show you how to use the Couchbase Lite for React Native - Native Module in a real-world application.  The apps are built using React Native and the Couchbase Lite for React Native.

== React Native Module Example App

The @couchbase/couchbase-lite-react-native module has an example app in the repository's https://github.com/couchbase/couchbase-lite-react-native/tree/main/expo-example[expo-example] folder. This example app is designed to show off all the various APIs and is used to test the Native Module during the development process.

== Expo Travel Sample App

The https://github.com/couchbase-examples/expo-cbl-travel[Expo Travel Sample App] is an example app that uses the Couchbase Capella free-tier and Travel-Sample dataset to show off a list of locations and hotels.
