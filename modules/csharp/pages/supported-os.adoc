[#not-officially-supported]
== Not Officially Supported

The following run-times are compatible but are not QE tested, and so are not officially supported.

[cols="1,^2,^2", options="header"]
|===
.>|.NET Runtime .>|Minimum Runtime Version .>|Minimum OS version
|.NET Mac
| 8.0
|14

|.NET Linux
| 8.0
|n/a*
|===

*{sp}There are many different variants of Linux, and testing resources are limited.
Couchbase Lite has been shown to work on CentOS, and in theory it works on any distro supported by .NET.
